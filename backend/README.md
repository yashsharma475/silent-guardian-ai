# Silent Guardian AI - Backend Service

Node.js + Express REST API providing state management, deterministic safety analysis, incident timeline tracking, and tamper-evident SHA-256 evidence sealing.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run in Development Mode
```bash
npm run dev
```
Starts backend server on `http://localhost:5000`.

### 3. Build & Production Start
```bash
npm run build
npm run start
```

## Render Deployment
- **Environment**: Node
- **Root Directory**: `backend`
- **Build Command**: `npm install && npm run build`
- **Start Command**: `npm run start`
